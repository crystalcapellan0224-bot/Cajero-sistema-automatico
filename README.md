# Cajero-sistema-automatico
 Simulador completo de un cajero automático web con autenticación segura, operaciones bancarias transaccionales (retiros, depósitos y transferencias), auditoría de movimientos y panel de supervisión.
 
Qué podés hacer:

Iniciar sesión con seguridad (y bloqueo si fallás muchas veces el PIN)
Ver tu saldo y tus últimas transacciones
Sacar y depositar dinero con comprobantes
Transferir a otros usuarios
Un asistente de chat para consultar
Cerrar sesión y ver el resumen de todo lo que hiciste
